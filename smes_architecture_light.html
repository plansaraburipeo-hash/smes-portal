แผนผังสถาปัตยกรรมระบบ S-MES (ฉบับสมบูรณ์)

Strategic Management & Evaluation System
ระบบบริหารจัดการและประเมินผลเชิงยุทธศาสตร์ รองรับสถาปัตยกรรมคู่ขนาน (Dual-Deployment: GAS Web App & Standalone GitHub Pages) พร้อมบูรณาการ Google Gemini AI & LINE Platform

🖥️ ชั้นส่วนหน้า (Frontend Layer) — ส่วนแสดงผลและประสบการณ์ผู้ใช้ HTML5 · Single Page Application (SPA) · Tailwind CSS & Glassmorphism
📄 ไฟล์หลัก (Entry Point & Presentation)
📋 Index.html
HTML Shell & Layout โครงสร้างหน้าจอหลัก, Navigation Sidebar (แยก 3 กลุ่มงาน + บริหารระบบ), กระดิ่งแจ้งเตือน Real-time Drawer
⚡ JS.html
UI Logic & Controllers จัดการสคริปต์หน้าจอ, SweetAlert2, Dynamic Forms, คำนวณงบประมาณ และ Universal RPC Bridge Client
🎨 CSS.html
Design System & Styling การจัดวางเลย์เอาต์, โหมดสีพรีเมียม (Forest/Emerald Theme), แอนิเมชัน และ Responsive สำหรับมือถือ
🚀 Dual-Deployment Support:
• GAS Web App: รันตรงบน Google Apps Script (`google.script.run`)
• Standalone Web: คอมไพล์ผ่าน `build-pages.js` สู่ `dist/index.html` เพื่อรันบน GitHub Pages / เซิร์ฟเวอร์สำนักงาน

⚙️ ชั้นประมวลผล (Backend Layer) — Google Apps Script (GAS) Services 14 บริการแยกตามกลุ่มภารกิจ · Session Token & Role-Based Authorization · AI-Powered Backend
🔐
ศูนย์กลางความปลอดภัย การยืนยันตัวตน และการตั้งค่าระบบ (Core Auth, Security & Config)
แฮชรหัสผ่าน SHA-256 ผสม Unique Salt + Global Pepper, ตรวจสอบ Session Token ทุกฟังก์ชัน, และระบบกู้รหัสผ่านทางอีเมล (Token 15 นาที)
🔑 Backend_Auth.js (สิทธิ์/เข้าสู่ระบบ/MailApp Reset) ⚙️ รหัส.js (Universal RPC Router / doGet / doPost / Config)
📁 1. กลุ่มนโยบายและแผน 4 บริการ + AI
📊 ภาพรวมแดชบอร์ด
Backend_Dashboard.js รวมข้อมูลข้ามกลุ่ม (Projects, Finance, PDEV, WFH, OIT) เพื่อแสดงผลภาพรวม KPI
🧮 จัดสรรและโยกงบประมาณ
Backend_Finance.js จัดการงบโครงการ, ยอดจัดสรร, บันทึกการโอนเงิน (Ledger) และระบบล็อกงวดงบประมาณ
📋 โครงการและแผนงาน (Gantt) Gemini AI
Backend_Projects.js จัดการโครงการ/Gantt และเชื่อมต่อ Google Gemini AI อ่านไฟล์เสนอโครงการแล้วถอดเป็น JSON อัตโนมัติ
📈 รายงานผลไตรมาส
Backend_Reports.js บันทึกผลงาน Q1-Q4, สรุปปัญหาอุปสรรค, แนบภาพกิจกรรม และระบบ AI สกัดข้อมูลรายงานผล
👥 2. กลุ่มบริหารงานบุคคล 3 บริการ
🛡️ ติดตาม OIT (ITA)
Backend_OIT.js จัดการตัวชี้วัด OIT รายข้อ (O1-O43), ตรวจสอบหลักฐาน และเปิด/ปิดการเผยแพร่
🎒 พัฒนาบุคลากร (PDEV)
Backend_PDEV.js สะสมชั่วโมงพัฒนาตนเอง, แนบประกาศนียบัตร และระบบคำขอแก้ไขข้อมูล (Edit Requests)
📢 ร้องเรียน / ทุจริต
Backend_Complaints.js ชั้นความลับข้อมูลร้องเรียน (Confidentiality), ตรวจสอบสถานะ และแจ้งเตือนผู้รับผิดชอบ
🏢 3. กลุ่มอำนวยการ 2 บริการ
🕒 Work From Home (WFH)
Backend_WFH.js ขออนุมัติ WFH, ลงเวลาเข้า-ออกงาน, ส่งรายงานผลงานประจำวัน และสรุปสถิติ (No GPS)
📅 ปฏิทินวาระงาน & ส่งออก
Backend_Calendar.js บันทึกวาระงาน, Sync Google Calendar, ดึงวันหยุดไทย iCal, และ Export Word (.docx) อัตโนมัติ
⚙️ 4. บริหารระบบ & แจ้งเตือน 4 บริการ
🛡️ ระบบแอดมิน / Archive
Backend_Admin.js การย้ายข้อมูลประวัติโครงการ (Archive Data), จัดการบัญชีผู้ใช้ และสิทธิ์กลุ่มงาน
📜 ประวัติแจ้งเตือนในระบบ
Backend_Notifications.js บันทึกประวัติการแจ้งเตือน, แจกจ่ายข้อความเตือน และส่งต่อไปยังแอป LINE
💬 LINE Integration & Triggers
Backend_Line.js
• ผูกบัญชีผู้ใช้ S-MES กับ LINE ID (Webhook Link)
• ยิงสรุปวาระงานประจำวัน (Daily Digest Broadcast)
• แจ้งเตือนโครงการและ WFH (Real-time Flex Messages)
📂 เอกสารเผยแพร่ & Drive
Drive Integration คลังไฟล์คู่มือ, ข้อเสนอโครงการที่อนุมัติ และเอกสารสาธารณะ
⚡ การเชื่อมโยงข้ามโมดูล: โครงการ ⇄ งบประมาณ (Finance Ledger) | อัปโหลดเอกสาร ➔ วิเคราะห์ด้วย Google Gemini AI ➔ กรอกฟอร์มอัตโนมัติ | ทุกเหตุการณ์เตือน ➔ บันทึก (Notifications) ➔ ยิงเข้า (แอป LINE) | ทุกโมดูล ➔ สรุปยอด KPI ผู้บริหาร (Dashboard)
🗄️ ชั้นฐานข้อมูล (Data Layer) — Google Sheets Database SpreadsheetApp NoSQL Model · 36 ตารางชีตครอบคลุมทุกสายงาน
📁 โครงการ & กิจกรรม
Projects, ActivityPlans ข้อมูลโครงการ/Gantt แผนงาน
💰 งบประมาณ & บัญชี
Budgets, Ledger ยอดจัดสรร, ประวัติโอน & หมวดจ่าย
📈 รายงานผลไตรมาส
Reports Sheet ผลการดำเนินงาน Q1-Q4
🛡️ ตัวชี้วัด OIT (ITA)
OIT_Tracking, ITA_Scores ข้อมูล ITA และคะแนนประเมิน
🎒 พัฒนาบุคลากร
PDEV_Records, Requests สมุดพก, เกียรติบัตร & คำขอแก้ไข
📢 เรื่องร้องเรียน
Complaints (Form Rep) ข้อร้องทุกข์ & ร้องเรียนทุจริต
🕒 บันทึก WFH (No GPS)
Attendance_Logs คำขอ & ประวัติเวลาเข้า-ออกงาน
📅 ปฏิทินวาระงาน
CalendarData, DutyTeams วาระผู้บริหาร & ทีมเวรสำนักงาน
📑 เอกสาร & SDGs
Documents, SDGsMaster คลังไฟล์เอกสาร & เป้าหมาย 17 SDGs
📦 ตารางควบคุมระบบ ความปลอดภัย และบันทึกประวัติ (Archive & Logs):
Users, Sessions, ResetTokens Projects_Archive, Reports_Archive APILogs (Gemini AI Tokens) ProjectLogs, Budget_Logs
🌐 บริการภายนอกและปัญญาประดิษฐ์ (External Services & AI APIs) Integrated Ecosystem
✨ Google Gemini AI Engine (Generative AI)
gemini-3.8-flash / gemini-2.5-flash
• อ่านและสกัดข้อมูลข้อเสนอโครงการ (วัตถุประสงค์, งบประมาณ, ตัวชี้วัด) อัตโนมัติ
• วิเคราะห์เอกสารรายงานผลไตรมาส และบันทึกการใช้งาน Token ลงชีต APILogs
💬 แพลตฟอร์มแอปพลิเคชัน LINE (LINE Messaging API)
Messaging API / Webhook Endpoint
• ผูกบัญชีผู้ใช้เมื่อพิมพ์ ผูกบัญชี:username ผ่าน Webhook
• ส่งรายงานสรุปงานประจำวัน (Automated Daily Digest) & Flex Messages ทันที
📁 Google Drive Service (DriveApp)
DriveApp API จัดเก็บไฟล์แนบโครงการ, หลักฐาน OIT, รูปถ่ายกิจกรรม และโฟลเดอร์ Archive ประจำปี
📅 Google Calendar, Mail & Docs Service
CalendarApp · MailApp · DocumentApp
• CalendarApp: ซิงค์วาระงาน พร้อมดึงวันหยุดราชการไทยจาก iCal Feed
• MailApp: ส่งอีเมลแจ้งลิงก์รีเซ็ตรหัสผ่านแบบจำกัดเวลา (15 นาที)
• DocumentApp: แปลงสรุปวาระงานเป็นไฟล์เอกสาร Word (.docx)
