แผนผังสถาปัตยกรรมระบบ S-MES

Strategic Management & Evaluation System
ระบบบริหารจัดการและประเมินผลเชิงยุทธศาสตร์ บนแพลตฟอร์ม Google Apps Script & Google Sheets

🖥️ ชั้นส่วนหน้า (Frontend Layer) — ส่วนแสดงผลและประสบการณ์ผู้ใช้ HTML5 · Single Page Application (SPA) · Browser Runtime
📄 ไฟล์หลัก (Entry Point & Controllers)
📋 Index.html
HTML Shell & Layout หน้าจอหลัก, Navigation Sidebar (แยก 3 กลุ่มงาน + ส่วนสนับสนุน), กระดิ่งแจ้งเตือน Real-time
⚡ JS.html
UI Logic & Controllers จัดการสคริปต์หน้าจอ, SweetAlert2, Dynamic Forms, คำนวณงบประมาณ และเรียกเซิร์ฟเวอร์
📱 โมดูลย่อยบนหน้าจอ (UI Sub-Modules ตามแถบเมนูจริง)
📁 กลุ่มนโยบายและแผน
  • 📊 ภาพรวม (Dashboard)
  • 🧮 จัดสรร/โยกงบประมาณ
  • 📅 ติดตามแผนงาน (Gantt)
  • 💰 วางแผนกิจกรรม
  • 🌐 โครงการทั้งหมด
  • 📋 รายการโครงการ
  • 📈 รายงานผล (ไตรมาส)
👥 กลุ่มบริหารงานบุคคล
  • 🛡️ ติดตาม OIT (ITA 43 ข้อ)
  • 🎒 พัฒนาบุคลากร (PDEV)
  • 📢 ระบบร้องเรียน ร้องทุกข์
  • ⚖️ ระบบร้องเรียนทุจริต
🏢 กลุ่มอำนวยการ & อื่นๆ
  • 🕒 Work From Home (WFH)
  • 📅 ปฏิทินวาระงาน
  • 📂 เอกสารเผยแพร่
  • ⚙️ จัดการระบบ (Admin)
  • 📜 ประวัติแจ้งเตือน / โปรไฟล์
⚙️ ชั้นประมวลผล (Backend Layer) — Google Apps Script (GAS) Services 13 บริการแยกตามกลุ่มภารกิจ · Session Token & Role-Based Authorization
🔐
ศูนย์กลางการยืนยันตัวตนและการตั้งค่า (Core Authentication & System Config)
ทุกฟังก์ชันของทุกกลุ่มงานต้องผ่านการตรวจสอบ Session Token และสิทธิ์เฉพาะทางก่อนประมวลผล
🔑 Backend_Auth.js (สิทธิ์/เข้าสู่ระบบ/โปรไฟล์) ⚙️ รหัส.js (Global CONFIG & SystemConfig)
📁 1. กลุ่มนโยบายและแผน 4 บริการ
📊 ภาพรวมแดชบอร์ด
Backend_Dashboard.js รวมข้อมูลข้ามกลุ่ม (Projects, Finance, PDEV, WFH, OIT) เพื่อแสดงผลภาพรวม KPI
🧮 จัดสรรและโยกงบประมาณ
Backend_Finance.js จัดการงบโครงการ, ยอดจัดสรร, บันทึกการโอนเงิน และเชื่อมต่อยอดกับรายการโครงการ
📋 โครงการและแผนงาน (Gantt)
Backend_Projects.js ติดตามแผนงาน Gantt, กิจกรรม, โครงการทั้งหมด, แนบเอกสาร Drive และประเมินผล
📈 รายงานผลไตรมาส
Backend_Reports.js บันทึกผลการดำเนินงาน, ปัญหาอุปสรรค, แนบไฟล์รายงาน และจัดทำสรุปภาพรวม
👥 2. กลุ่มบริหารงานบุคคล 3 บริการ
🛡️ ติดตาม OIT (ITA)
Backend_OIT.js จัดการตัวชี้วัด OIT รายข้อ (o1-o43), ตรวจสอบหลักฐาน และเปิด/ปิดการเผยแพร่
🎒 พัฒนาบุคลากร (PDEV)
Backend_PDEV.js สะสมชั่วโมงพัฒนาตนเอง, แนบประกาศนียบัตร และออกรายงานสถิติบุคคล
📢 ร้องเรียน / ทุจริต
Backend_Complaints.js ชั้นความลับข้อมูลร้องเรียน, ตรวจสอบสถานะ, แจ้งเตือนผู้รับผิดชอบ และสรุปสถิติ
🏢 3. กลุ่มอำนวยการ 2 บริการ
🕒 Work From Home (WFH)
Backend_WFH.js ขออนุมัติ WFH, ลงเวลาเข้า-ออกงาน, ส่งรายงานผลงาน และตรวจสอบสถิติ ✔️ ไม่มีการบันทึกพิกัดตำแหน่ง
📅 ปฏิทินวาระงาน
Backend_Calendar.js บันทึกวาระงาน, นัดหมายผู้บริหาร, แจ้งเตือน และเชื่อมโยงกับ Google Calendar
⚙️ 4. บริหารระบบ & แจ้งเตือน 4 บริการ
🛡️ ระบบแอดมิน / Archive
Backend_Admin.js การย้ายข้อมูลประวัติโครงการ (Archive Data), จัดการบัญชีผู้ใช้ และสิทธิ์กลุ่มงาน
📜 ประวัติแจ้งเตือนในระบบ
Backend_Notifications.js บันทึกประวัติการแจ้งเตือน, แจกจ่ายข้อความเตือน และส่งต่อไปยังแอป LINE
💬 เชื่อมต่อแอปพลิเคชัน LINE (LINE Integration)
Backend_Line.js
ระบบแจ้งเตือนและสื่อสารอัจฉริยะ (LINE Messaging API & Webhook):
• ผูกบัญชีผู้ใช้ S-MES กับ LINE ID (Account Linking via Webhook)
• ส่งรายงานวาระงานประจำวันอัตโนมัติ (Automated Daily Digest)
• แจ้งเตือนสถานะโครงการและ WFH แบบทันที (Real-time Flex Messages)
📂 เอกสารเผยแพร่
Drive Integration คลังไฟล์คู่มือ, ข้อเสนอโครงการที่อนุมัติ และเอกสารสาธารณะ
⚡ การเชื่อมโยงข้ามโมดูล: โครงการ (Projects) ⇄ งบประมาณ (Finance) | ทุกเหตุการณ์เตือน ➔ บันทึก (Notifications) ➔ ยิงเข้า (แอป LINE) | ทุกโมดูล ➔ ประมวลผลภาพรวม (Dashboard)
🗄️ ชั้นฐานข้อมูล (Data Layer) — Google Sheets SpreadsheetApp NoSQL Model · แยกชีตตามบริบทงาน
📁 โครงการ & แผน
Projects, Activities ข้อมูลโครงการ/Gantt
💰 งบประมาณ
BudgetAllocations ยอดจัดสรรและประวัติโอน
📈 รายงานไตรมาส
Reports Sheet ผลการดำเนินงาน Q1-Q4
🛡️ ตัวชี้วัด OIT
OIT_Items, Evidence ข้อมูล ITA 43 ตัวชี้วัด
🎒 พัฒนาบุคลากร
PDEV_Records ประวัติการอบรมบุคลากร
📢 เรื่องร้องเรียน
Complaints Sheet ข้อร้องทุกข์ & ทุจริต
🕒 บันทึก WFH
WFH_Requests, Logs คำขอ & บันทึกเวลาทำงาน
⚙️ ผู้ใช้ & ตั้งค่า
Users, SystemConfig สิทธิ์, โทเคน, แจ้งเตือน
🌐 บริการภายนอก (External APIs) Third-Party
💬 แพลตฟอร์มแอปพลิเคชัน LINE (LINE Messaging Platform)
LINE Messaging API / Webhook Endpoint
• รับ Webhook เชื่อมบัญชีผู้ใช้เมื่อพิมพ์ ผูกบัญชี:username
• ยิงแจ้งเตือนสรุปงานประจำวัน (Daily Digest) และสถานะอนุมัติสู่สมาร์ตโฟนทันที
📁 Google Drive Service
DriveApp / Drive API จัดเก็บไฟล์แนบโครงการ, หลักฐาน OIT, รูปภาพ และโฟลเดอร์ Archive ประจำปี
📅 Google Calendar Service
CalendarApp API ซิงค์วาระงานผู้บริหารและการประชุมลงใน Google Calendar อัตโนมัติ
📌 คำอธิบายสัญลักษณ์และการทำงานเชื่อมโยง (System Insights)
📁
กลุ่มนโยบายและแผน
ควบคุมวัฏจักรโครงการ งบประมาณ และการรายงานผลไตรมาส
👥
กลุ่มบริหารงานบุคคล
ดูแลความโปร่งใส ITA (OIT), ชั่วโมงพัฒนาตนเอง (PDEV) และข้อร้องเรียน
🏢
กลุ่มอำนวยการ
บริหารการลงเวลาปฏิบัติงานนอกสถานที่ (WFH) และปฏิทินวาระงาน
💬
แอปพลิเคชัน LINE (LINE Integration)
ช่องทางแจ้งเตือนอัจฉริยะ (Daily Digest & Real-time Alerts) ผ่าน LINE Messaging API
