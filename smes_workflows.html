0.2 วงจรการไหลของข้อมูลหลัก 6 วงจร (The 6 Core Operational Data Loops)

การทำงานเชื่อมโยงแบบไร้รอยต่อ
1️⃣ วงจรยุทธศาสตร์และงบประมาณ
กระบวนการ: บุคลากรเสนอโครงการ (ใช้ AI ช่วยดึงข้อมูล) ➔ เข้าคิว LockService ➔ ผู้บริหารอนุมัติ ➔ ผูกบัตรงบประมาณ Card No. ➔ จัดสรร/โอนงบประมาณ (Transfer Batch) ➔ ดำเนินกิจกรรม Gantt ➔ รายงานผลไตรมาส (Q1-Q4) ➔ คำนวณ % ความก้าวหน้าสะสม
Projects ➔ Budgets ➔ Reports
2️⃣ วงจรธรรมาภิบาลและความโปร่งใส (ITA)
กระบวนการ: กำหนดตัวชี้วัด o1-o43 ➔ มอบหมายกลุ่มงานผู้รับผิดชอบ ➔ อัปโหลดไฟล์หลักฐานขึ้น Google Drive / ระบุ URL ➔ คณะกรรมการตรวจและรับรอง ➔ สรุปคะแนนองค์กร ITA_Scores ➔ เผยแพร่สาธารณะ ➔ รับเรื่องร้องเรียน/ทุจริตผ่าน Ticket ลับ
OIT_Data ➔ ITA_Scores ➔ Complaints
3️⃣ วงจรบริหารทุนมนุษย์ (HR Capital)
กระบวนการ: อบรม/พัฒนาตนเอง ➔ แนบหลักฐานเกียรติบัตร ➔ เจ้าหน้าที่บุคคลตรวจอนุมัติชั่วโมงสะสม (รอบ 1/รอบ 2) ➔ ยื่นขอแก้ไขกรณีมีข้อผิดพลาด ➔ ลงเวลาปฏิบัติงานนอกสถานที่ (WFH ปลอด GPS ตาม PDPA) ➔ สรุปผลงาน
PDEV_Records ➔ Attendance_Logs
4️⃣ วงจรสื่อสารและแจ้งเตือนอัจฉริยะ (LINE)
กระบวนการ: ผู้ใช้ส่ง ผูกบัญชี:username ผ่าน LINE OA ➔ Webhook บันทึก LINE UID ➔ เมื่อมีเหตุการณ์สำคัญ (อนุมัติโครงการ, โอนงบ, ลงนัดหมาย) ยิง Flex Card แจ้งเตือน Real-time ➔ ทริกเกอร์อัตโนมัติ 07:00 น. ส่ง Daily Digest รายวันสู่มือถือ
Backend_Line ➔ LINE Messaging API
5️⃣ วงจรสารสนเทศผู้บริหาร (FVCT)
กระบวนการ: รวมข้อมูลจาก 5 ชีต (โครงการ, งบประมาณ, PDEV, WFH, OIT) ➔ ประมวลผลดัชนี FVCT (Fast, Value, Clear, Team) ➔ คำนวณสถิติเบิกจ่ายและร้อยละความสำเร็จ ➔ แสดงผล Dashboard แบบ Interactive พร้อม Chart.js กราฟแท่งและโดนัท
Executive Dashboard ➔ Chart.js
6️⃣ วงจรความมั่นคงปลอดภัยและจัดการระบบ
กระบวนการ: สมัครสมาชิก ➔ แอดมินอนุมัติและระบุกลุ่มงาน ➔ ล็อกอินยืนยันตัวตนด้วย Salt+Pepper ➔ ออก Session Token (8 ชม.) ➔ คัดกรองผ่าน Allowlist 117 ฟังก์ชัน ➔ จัดการคีย์ Gemini AI ➔ สำรองข้อมูลประวัติประจำปี (Archive) ลง Google Drive
Users ➔ SystemConfig ➔ Archive

0.3 ตารางเมทริกซ์การเชื่อมต่อข้อมูลข้ามโมดูล (Cross-Module Interaction Matrix)

Data Dependencies
โมดูลต้นทาง (Source) ข้อมูลที่ส่งต่อ (Data / Payload) โมดูลปลายทาง (Target) ผลลัพธ์ทางธุรกิจและการทำงานร่วมกัน (Business Value)
Backend_Projects รหัสโครงการ, วงเงิน, กลุ่มงาน, Card No. Backend_Finance ผูกบัตรประจำโครงการเข้ากับหมวดงบประมาณเพื่อควบคุมยอดเงินและป้องกันการเบิกเกินวงเงิน
Backend_Projects รายชื่อโครงการที่ผ่านการอนุมัติ Backend_Reports เปิดสิทธิ์ให้ผู้รับผิดชอบสามารถกรอกรายงานผลประจำไตรมาส (Q1 - Q4) ได้เฉพาะโครงการที่ผ่านการอนุมัติแล้ว
Backend_Reports ร้อยละความก้าวหน้าสะสม, ยอดใช้จ่ายจริง Backend_Projects อัปเดตช่อง "ความก้าวหน้าล่าสุด %" และ "เบิกจ่ายสะสม" ในชีต Projects แสดงผลบน Gantt Chart ทันที
ทุกโมดูลในระบบ ยอดสรุปสถิติ, KPIs, ดัชนีตัวชี้วัด Backend_Dashboard ดึงข้อมูลคำนวณดัชนี FVCT และเรนเดอร์กราฟภาพรวมผลการดำเนินงานระดับจังหวัดสำหรับผู้บริหาร
Backend_Calendar วาระการประชุม, วันเวลา, สถานที่, รายชื่อผู้เข้าร่วม Google Calendar & LINE ซิงค์ลงปฏิทินองค์กรอัตโนมัติ และยิง Flex Message แจ้งเตือนผู้เกี่ยวข้องผ่านแอปพลิเคชัน LINE
Projects / Finance / WFH / Calendar สัญญาณอีเวนต์สถานะ (อนุมัติ, ส่งกลับ, แจ้งเตือน) Backend_Notifications & LINE บันทึกลงกระดิ่งแจ้งเตือนในระบบเว็บ และ Push Notification เข้าสมาร์ตโฟนบุคลากรแบบ Real-time
🔗 0.4 การเชื่อมต่อบริการภายนอกเชิงลึก (External Services Integration Deep-Dive) External APIs & Automated Triggers
📁

1. Google Drive API (DriveApp)

• วัตถุประสงค์: คลังจัดเก็บเอกสารและหลักฐานดิจิทัลทั้งหมดของระบบ
• โครงสร้างโฟลเดอร์: ฟังก์ชัน getDynamicFolderId() แยกโฟลเดอร์ตามปีงบประมาณอัตโนมัติ
• ไฟล์ที่รองรับ: ข้อเสนอโครงการ (Word, PDF), บันทึกขอแก้ไข, หลักฐาน OIT (PDF, Image), เกียรติบัตร PDEV, รูปกิจกรรมรายงานผลไตรมาส
• ความปลอดภัย: แปลง Base64 ก่อนอัปโหลด ตั้งชื่อไฟล์ตามมาตรฐาน ID_ชื่อโครงการ_ประเภท และกำหนดสิทธิ์ View Only
uploadAndRenameFile() ➔ DriveApp
📅

2. Google Calendar API (CalendarApp)

• วัตถุประสงค์: ซิงค์วาระงานของผู้บริหาร, การประชุมประจำสัปดาห์ และทีมเวรประจำวัน
• การเชื่อมโยง: เมื่อบันทึกนัดหมายใน saveCalendarEvent() ระบบจะเรียก CalendarApp.createEvent() อัตโนมัติ
• รายชื่อผู้เข้าร่วม: ค้นหาอีเมลบุคลากรจากชีต Users มาใส่ใน Guest List และแนบลิงก์สถานที่/Google Meet
• ฟังก์ชันพิเศษ: เชื่อม API วันหยุดราชการจาก MyHora และส่งออกรายงานวาระงานประจำเดือนเป็นไฟล์ Docx อัตโนมัติ
CalendarApp.getDefaultCalendar()
💬

3. LINE Messaging API & Webhook

• วัตถุประสงค์: สื่อสารสองทาง (Two-Way Communication) แจ้งเตือนเรียลไทม์ และสรุปงานประจำวัน
• Webhook Endpoint: รับข้อความผ่าน doPost(e) ใน รหัส.js ดักจับคำสั่ง ผูกบัญชี:username บันทึก LineUserId ลงชีต Users
• Push Notification: ยิงการ์ด Flex Message เข้ามือถือผู้เกี่ยวข้องทันทีเมื่อโครงการอนุมัติ, โอนงบ, หรือมีนัดหมายใหม่
• ระบบ Quick Reply: ผู้ใช้พิมพ์เรียกดู "วาระงานวันนี้", "โครงการของฉัน" หรือ "เมนูหลัก" ผ่านแชตบอทได้ทันที
UrlFetchApp ➔ LINE Platform
🤖

4. Gemini AI API (Document Analysis)

• วัตถุประสงค์: ผู้ช่วยอัจฉริยะวิเคราะห์และสกัดข้อมูลจากไฟล์ Word/PDF เสนอโครงการ
• การทำงาน: ฟังก์ชัน importProjectFromBlob() ส่งไฟล์ให้โมเดล Gemini แยกแยะชื่อโครงการ, วัตถุประสงค์, งบประมาณ, ตัวชี้วัด ออกมาเป็น JSON
• ระบบคลังคีย์ (API Key Rotation): หมุนเวียนคีย์สำรองอัตโนมัติ ตรวจสอบโควตา บันทึก Log การใช้โทเคน (Input/Output)
• ความปลอดภัย: เข้ารหัสและซ่อนคีย์ API (Masking: AIzaSy...****) ไม่เปิดเผยใน Client-side
importProjectFromBlob() ➔ Gemini REST API
⏰

5. Time-Driven Triggers (Cron Services)

• วัตถุประสงค์: ประมวลผลเบื้องหลังตามกำหนดเวลาอัตโนมัติโดยไม่ต้องมีผู้ใช้งานเปิดหน้าเว็บ
• Daily Digest (07:00 น. ทุกวัน): ฟังก์ชัน sendLineDailyDigest() รวบรวมวาระงานวันนี้ของแต่ละคน ยิงสรุปเตือนยามเช้า
• Session Cleaner: ตรวจสอบและเพิกถอน Session Token ที่มีอายุเกิน 8 ชั่วโมง ป้องกันการค้างของเซสชัน
• Annual Archive: ฟังก์ชัน archiveDataAdmin() รวบรวมข้อมูลโครงการสิ้นปีงบประมาณและบันทึกลงโฟลเดอร์ Archive
ScriptApp.newTrigger() ➔ sendLineDailyDigest()
